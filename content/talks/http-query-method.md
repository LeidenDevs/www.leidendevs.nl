In June 2026, a new HTTP verb was approved: [QUERY]. Why did the HTTP Working Group
add a new method for the first time since 2010? Michiel will explain which problems
this newest verb is designed to solve and how to use it.

[QUERY]: https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods/QUERY
